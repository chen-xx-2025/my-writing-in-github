## 为什么使用Markdown来写作？
1. 很多格式都可通过Markdown来转换。昨天还在找什么手机APP可以写markdown，原来Github就可以。
2. 非常结构化。结构思考力，是非常重要的思维方式。
3. 沉浸式写作。锻炼自己的写作能力，什么都写。写作是思考的工具，写多了，头脑自然清晰，表达自然逻辑强。

## HOW写作方法或者技巧
1. 使用的词语越简单越好，不明白的词汇不使用。就怕不知道表达什么，更怕啰啰嗦嗦还没有讲明白。
2. 李笑来说，写教程。自己会的，写出来。

## WHY需要写作的案例
1. 面试时，发现很多面试者回答问题使用的词汇非常匮乏。缺乏归纳。
